Deutsch250 — Beautiful MVP

Files:
- index.html  : page structure
- styles.css : responsive visual design + dark mode
- app.js     : 250-word data + filters + progress + quiz + pronunciation

How to run:
1. Open index.html in a modern browser.
2. Or upload this entire folder to Netlify / GitHub Pages.

Features:
- 250 words across A1, A2, B1, B2 and C1
- Search and status filtering
- Local progress tracking
- Pronunciation through the browser Speech Synthesis API
- 10-question quiz rounds with score
- Light / dark mode
- Responsive mobile layout
- No backend required

- English / Azerbaijani translation toggle (EN ↔ AZ)
- Quiz answers automatically use the selected translation language
